# Data contract quality

- Preserve exact identifiers, leading zeroes, currencies and fractional precision according to the brief.
- Confirm inferred types and intended constraints against the domain. Validate duplicate, missing and wrong-type values deliberately in a test fixture.
- Ensure all intended resources appear in the report. Check the copied package with only the files that will actually be delivered.
- Reconcile row counts and business totals separately. Passing the file contract does not establish those results.
